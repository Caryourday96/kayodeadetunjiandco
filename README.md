# Kayode Adetunji & Co.

Preliminary responsive website design for the accounting practice.

## Preview

Open `index.html` in a browser. No installation, build step, external fonts, or third-party requests are required. The complete website consists of `index.html`, `styles.css`, `script.js`, and `favicon.svg`.

## Design

Navy, soft white, and gold; editorial serif headings; responsive service sections; accessible mobile navigation; keyboard focus styling; reduced-motion support.

## Confirm before launch

- Business name styling and approved introductory copy.
- Actual service offering: accounting/bookkeeping, tax, and advisory are proposed copy, not verified services.
- Email, telephone number, office address, and service region.
- Any professional designations, registrations, or legal disclosures that should appear.

The draft notice is intentional. No credentials, client endorsements, operating history, or results are claimed. Contact details are marked as pending. There is no contact form or simulated message delivery, and the site collects no personal information.

## Hosting

The files are suitable for any static hosting service, including GitHub Pages. This commit supplies the design source; hosting is not enabled by the project itself.
